
# UndefinedVerseOfficial — Content Guide

## 1. Purpose

This guide defines how content is written, organized, and presented across UndefinedVerseOfficial.

All published content should be clear, consistent, original, and honest about its current status.

## 2. Manga

The Manga section is under development until genuine, approved works are ready to publish.

- Publish only confirmed titles.
- Use accurate descriptions and chapter information.
- Do not create placeholder titles that appear to be real works.
- Clearly label unfinished features.
- Add cover artwork only when suitable assets are available.

## 3. Novels

The Novels section follows the same publishing standards.

- Publish only genuine, approved projects.
- Keep summaries faithful to the actual story.
- Show chapter availability accurately.
- Do not invent authors, release dates, or publication details.
- Keep unpublished works clearly marked as in development.

## 4. Codex

The Codex is intended for documented fictional lore, concepts, terminology, and worldbuilding associated with UndefinedVerseOfficial.

- Distinguish fictional worldbuilding from real-world facts.
- Keep terminology and established lore consistent.
- Do not present speculative concepts as scientifically proven.
- Do not add entries merely to make the section appear complete.
- Identify unfinished material when appropriate.

## 5. About and Status

The About page should explain the project's purpose without exaggerated claims.

The Status page should describe the current state of features accurately.

- Do not claim a feature works unless it has been implemented and tested.
- Do not invent release dates or development milestones.
- Update status information when the project changes.
- Keep notices short and informative.

## 6. Writing style

Use a restrained, polished, and direct writing style.

Prefer:
- Clear headings.
- Short, useful paragraphs.
- Specific descriptions.
- Consistent terminology.
- Straightforward development notices.

Avoid:
- Forced dramatic dialogue.
- Excessive exclamation marks.
- Empty promotional language.
- Repeated statements that add no information.
- Claims that the website or its fictional concepts are real-world phenomena.

## 7. Content accuracy

Before publishing content, verify that:

1. The content is intentional and approved.
2. Names, descriptions, and links are correct.
3. The publication status is accurate.
4. The content displays properly on mobile and desktop.
5. Any required content warnings are clear and appropriate.

## 8. Empty and developing sections

An empty catalogue is preferable to fabricated entries.

When a section is not ready, explain its development status briefly. Do not use fake titles, fake statistics, or invented activity to make the website look populated.

## 9. Updates

Review this guide whenever the site's content structure or publishing process changes.
